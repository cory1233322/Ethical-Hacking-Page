What SSH Does

SSH provides encrypted remote access to another computer over a network. It replaced older insecure methods like Telnet.

Why It Matters

Without encryption, attackers could intercept login credentials. SSH prevents this by securing all communication between devices.

Example Command Breakdown

ssh student@192.168.1.100

student = username
192.168.1.100 = target device
ssh = secure connection protocol
